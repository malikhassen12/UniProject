# Standard Neural Net Baseline

MLP baseline implementation used for comparison against DeepONet 
in a data assimilation study on PDE-governed systems.

## Tech Stack
Python, PyTorch, NumPy

## Purpose
This branch implements a standard fully connected MLP architecture 
as the benchmark model. Results are compared against the DeepONet 
implementation in the `DeepOnet` branch.
