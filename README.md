# DeepONet Data Assimilation

Comparing DeepONet (operator learning networks) against standard MLP 
architectures for data assimilation in PDE-governed systems.

## Tech Stack
Python, PyTorch, NumPy

## What I did
- Designed experiments comparing model stability, accuracy, and generalisation
- Implemented DeepONet and MLP baselines in PyTorch
- Built a web app to visualise PDE solutions and model predictions

## Branches
- `DeepONet` — operator network implementation
- `StandardNeuralNet` — MLP baseline for comparison
