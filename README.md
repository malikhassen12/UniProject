# DeepONet Data Assimilation

## What is this?
A research project comparing DeepONet (operator learning networks) against 
standard MLP architectures for data assimilation in PDE-governed systems.

## Tech Stack
Python, PyTorch, NumPy

## What I did
- Designed and ran experiments comparing model stability, accuracy, and generalisation
- Implemented both DeepONet and MLP baselines in PyTorch
- Built a web app to visualise PDE solutions and model predictions
